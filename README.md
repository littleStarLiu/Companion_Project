# Zoey Agent • Alive Companion Web App

A modern, responsive web application for **Zoey Agent**, featuring:
- **Alive Presence**: Glowing profile avatar with real-time status indicator (*"🟢 Online • Reading by the window"*).
- **Bilingual Conversations**: Speaks English when spoken to in English, and Chinese when spoken to in Chinese.
- **Interactive Quick Prompts & Typing Indicators**.

## Quick Start

1. **Install Dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

2. **Set your Gemini API Key** (optional for live AI responses):
   ```bash
   export GEMINI_API_KEY="your-gemini-api-key"
   ```

3. **Start the Web App**:
   ```bash
   python app.py
   ```

4. **Open in Browser**:
   Visit [http://localhost:8000](http://localhost:8000)
